# 経費・報酬・帳簿・青色申告補助（第2・第3段階）の設計メモ

> この機能は「記録・集計・書類作成の補助」です。「これは経費になる」とは断定せず、最終確認は税理士が行う前提の注記を全画面に入れています（指示書 9）。

## 1. 流れ

```
レシート撮影 ──Claude vision──▶ 日付/店名/金額/科目候補 ──確認──▶ Expense（確定）
報酬明細（写真/PDF）──Claude──▶ 売上/歩合/報酬/控除/源泉/振込 ──確認・確定──▶ IncomeStatement
                                                          └─ 控除項目（材料費・場所代等）→ Expense（報酬から天引き）
Expense / IncomeStatement / OtherIncome ──自動仕訳──▶ 仕訳帳・総勘定元帳・試算表・P/L・B/S・決算書転記表
                                        └─ 月別科目別集計・経費帳・売掛帳・現金出納帳（簡易簿記）
                                        └─ 手取り見込み（所得税・住民税・国保・年金の概算）
開業届・青色申告承認申請書 ── 入力 → 記入用シート（期限計算つき）
```

## 2. モデル（`apps/ledger`）

| モデル | 内容 |
| --- | --- |
| `Receipt` | レシート画像/PDF。OCR結果（`ocr_raw`）と状態 |
| `Expense` | 経費。科目（`categories.py` の16科目）、事業使用割合（家事按分）、支払方法（現金 / 事業用口座 / 個人の財布=事業主借 / 報酬から天引き）、確定フラグ |
| `IncomeStatement` | 月ごとの報酬明細。技術売上・歩合率・報酬額・控除JSON・源泉・振込額・支払日。`balance_diff` が0でなければ読み漏れの警告 |
| `OtherIncome` | 報酬以外の事業収入 |
| `OpeningBalance` | 年初残高（現金・預金・売掛金）→ 元入金 |
| `ManualJournalEntry` | 自動仕訳で表せない取引の手入力 |
| `TaxSettings` | 見込み計算の前提（青色控除額・国民年金月額・国保料率と上限・その他控除・見込み月収/月経費） |
| `FilingProfile` | 開業届・青色申告承認申請書の記入項目 |

音声・写真と同様、画像は `MEDIA_ROOT/stylist_<id>/receipts|statements/` に美容師ごとに保存。

## 3. 科目と仕訳ルール

- 科目コードと決算書の勘定科目の対応は `apps/ledger/categories.py`。`materials`（材料費）は売上原価（仕入高）、それ以外は経費。
- 明細の控除ラベルは `deduction_category()` でキーワード判定（材料→materials、場所/面貸し→booth_rent、振込/手数料→fees …）。画面で変更可。
- 自動仕訳（`apps/ledger/journal.py`）:

| 取引 | 借方 | 貸方 | 日付 |
| --- | --- | --- | --- |
| 報酬の発生 | 売掛金 | 売上高 | 対象月の月末 |
| 明細の控除（材料費等） | 各経費科目 | 売掛金 | 対象月の月末 |
| 源泉徴収 | 事業主貸 | 売掛金 | 対象月の月末 |
| 報酬の入金 | 普通預金 | 売掛金 | 支払日 |
| 経費（現金） | 各経費科目 | 現金 | 支払日 |
| 経費（事業用口座・カード） | 各経費科目 | 普通預金 | 支払日 |
| 経費（個人の財布・カード） | 各経費科目 | 事業主借 | 支払日 |
| その他収入 | 現金 / 普通預金 | 雑収入 | 受取日 |
| 期首残高 | 現金 / 普通預金 / 売掛金 | 元入金 | 1/1 |

- 家事按分は事業分（`business_amount`）だけを仕訳。私用分は帳簿に載せない。
- 消費税は免税事業者を想定し、税区分は扱わない（CSVの税区分は「対象外」）。インボイス登録者・課税事業者は税理士に確認。
- 減価償却（10万円以上の器具）は科目 `depreciation` に年末に金額を手入力する簡易対応。固定資産台帳・償却計算は未実装。
- B/S は 資産（現金・普通預金・売掛金・事業主貸）= 元入金 ＋ 事業主借 ＋ 当期の所得（控除前）で検算（`balanced`）。

## 4. 出力（CSV）

| 出力 | 形式 | 注意 |
| --- | --- | --- |
| 仕訳帳 | 汎用（UTF-8 BOM） | 日付・借方・金額・貸方・摘要・区分 |
| 弥生会計 | 仕訳日記帳インポート形式 25列・ヘッダー無し・Shift_JIS | 識別フラグ 2000、税区分「対象外」。弥生側の勘定科目名と一致しない科目（研修費・面貸し料など）は取り込み時にマッピングが必要 |
| freee | 「取引」インポート形式（UTF-8 BOM） | 収入＝報酬（控除前）、支出＝経費の事業分。freee の最新テンプレートと列順を確認して取り込む |
| e-Tax 転記表 | 決算書の各欄＋確定申告書の概算値 | e-Tax の XML（.xtx）は生成しない。確定申告書等作成コーナーに転記する用途 |
| 経費・収入一覧 | CSV | 帳簿の控え・税理士への共有用 |

## 5. 手取り見込み（`apps/ledger/tax.py`）

1. 月ごとの実績（確定した報酬明細＋その他収入、確定した経費）を集計。実績のない「今月以降」は実績平均（または設定した見込み月収・月経費）で埋める。
2. 所得（控除前）= 収入 − 経費。青色申告特別控除は所得が上限。
3. 国民健康保険 ≒ (事業所得 − 43万) × 料率（既定 11%）、上限（既定 109万）。市区町村で大きく異なるため設定で変更。
4. 国民年金 = 月額（既定 17,920円）× 12。
5. 基礎控除は 2025年分以降の改正に対応（2025・2026年分は所得に応じて 95/88/68/63/58万、2027年以降は 95万 または 58万）。
6. 課税所得（1,000円未満切捨て）→ 所得税速算表 → 復興特別所得税 2.1% → 100円未満切捨て。
7. 住民税 ≒ (事業所得 − 社保 − その他控除 − 43万) × 10% ＋ 均等割 5,000円。
8. 手取り = 収入 − 経費 − 所得税 − 住民税 − 国保 − 年金。源泉徴収済みの分は「納付 / 還付の見込み」として別表示。

いずれも概算。年度の改正・自治体差・各種控除（配偶者・扶養・医療費・iDeCo等は「その他の所得控除」に合計で手入力）で変わる。

## 6. 開業届・青色申告承認申請書（`apps/ledger/filings.py`）

- 開業届: 開業日から1か月以内。青色申告承認申請書: その年の 3/15、または 1/16 以降の開業なら開業日から2か月以内。土日は翌営業日に繰り下げ（祝日は未考慮と注記）。
- 国税庁の様式に転記するための「記入用シート」（印刷可）を生成。PDF自体の自動記入は行わない（e-Tax ソフトからの電子提出を案内）。
- 業種「美容業」、所得の種類「事業所得」を既定値にしているが、雇用契約に近い実態の場合は給与所得となる可能性があるため、税理士確認を促す文言を入れている。

## 7. テスト

`apps/ledger/tests/`: 所得税の速算表と端数処理、基礎控除の境界（2026年分・2027年分）、国保・住民税、年間見込みの手計算例（収入300万・経費60万 → 手取り 1,778,460円）、見込み月の埋め方、申請期限（土日繰り下げ・1/15境界・既存事業者）、自動仕訳の貸借一致・B/S一致・決算書転記、帳簿集計、CSVの列数、OCR→経費/明細確定の画面フロー、テナント分離。
