設定手順
  1. LINE Developers でプロバイダーを作り、既存のLINE公式アカウントに「Messaging API」を有効化（LINE Official Account Manager › 設定 › Messaging API からも可）
  2. チャネル基本設定の「チャネルID」「チャネルシークレット」を上に入力
  3. Messaging API設定タブで「チャネルアクセストークン（長期）」を発行して入力
  4. 保存 → 上に表示される Webhook URL を Messaging API設定の Webhook URL に貼り、「Webhookの利用」をオン →「検証」
  5. このアプリで「接続を確認」
