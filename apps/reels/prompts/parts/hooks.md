# 作るもの：フック（最初の2秒の一言）を3案

- 指定された3つの種類で1案ずつ。種類の意味：
  - call（呼びかけ）：「〜で悩んでいる人へ」と見てほしい人に直接声をかける
  - result（結果先出し）：仕上がりや変化を先に言い切る（ただし保証はしない）
  - scene（悩みの映像）：悩んでいる場面を一言で描く（朝の鏡の前、湿気の日、など）
  - surprise（意外性）：思い込みをひっくり返す一言
  - local（地域）：地名を入れて近所の人に届ける
- 文字数は20字以内。テーマ（得意な悩み）の言葉を必ず入れる
- 誇大表現・釣り表現は使わない（「絶対」「誰でも」「必ず」「劇的」など）
- visual には「最初の2秒に映すもの」を短く（例：仕上がりの毛先のアップ）
- 出力：{"hooks": [{"type": "...", "text": "...", "visual": "..."}, ...]}（3つ）
